## 1. Ghidra artefacts to undo
- Gh inverts if/else (try both orders); drops parens: `a*b*c` may be `a*(b*c)` (0x17dab8).
- Signed `x/2^k` printed `if(x<0)x+=..;>>k`: write `x/2^k`; repeated subexpressions hoisted into temps (0xee44c).
- `for{if(hit){r=i;break;}}return r;` printed as early returns: keep the break form (0x2535f0).
- `i<=C` printed `i<C+1`: `i<=0x179` = `slti at`, `i<0x17a` = `slti v0`; try inclusive (0x1afcd4).
- `if(m==1){..}if(m==2){..}` printed merged via `t=m`: re-read m per test (0xdcca0).
- `lo<=x&&x<hi` printed as if/else-if chain: one `&&`; `v=obj?obj->f:-1;` for if/else assign (hstperm m_chain_merge, m_ternary) (0x1a47e8, 0xb13c4).
- Next stmt copied into both null-check arms: `if(p){act(p);m1=0;}t=m2;if(t)..` (hstgen 20/21, hstperm m_hoist) (0x2934ec); duplicated trailing store = one shared store (0x1b31ac); `if(a==b){if(flag==0){..}u=m;}else u=m;` = `if(a==b&&flag==0){..}` (0x1b5ff0); `(p!=0)&&(p!=0)` = `if(p){if(p){dtor(p,1);p=0;}}` (0xcabe0).
- Dtor `if(&this->m)` printed `this!=(T*)0xfffffc90`: `(char*)this+0x370!=0` (0x126c2c). Const-propagated default param (`(n*4+n)*4`): `if(n==0)n=C;`, `n*0x14+0x18` (0xfcbe4).
- `t=f();x=a+t` flips operands: `x=a+f();`; globals read before a call: later-loaded written second (0xfc820). `undefined4` float fields: check lwc1 vs lw (0x93654).

## 2. Call arguments, prototypes, argument order
- Empty variadic stubs: `extern "C" void f(...)` (0x8822c).
- Gh drops args of callees typed with fewer params or void (base ctors taking `this`, member object in a0 by a float): `move sN,aN` order / a0 loads before the jal reveal them (0x1140d0, 0x127a68); `move a0,v0;bltzl a0` = `F(r)`; `lw a0;beqz;lw a1;beqz;jal` = `F(self->a,self->b)` (0x92d10).
- Dtor `if(m!=0){FUN_000104e0();m=0;}` is `FUN_000104e0(m)` (hstgen v15) (0xbc6c0, 0xff548, 0xfcb7c).
- `li a1,-1;sw a1,456(s3)` + `jal F;move a0,s0`: -1 is F's dropped 2nd arg (0xc82c8, 0x15a62c, 0xcabe0, 0xc9088).
- Compare constant in an arg reg (`li a0,2;beq v0,a0,L`) = later call arg `r=G(2)` (0x10a8a0, 0x10acbc); `lw a2,28(sp);bgtzl a2` = dropped 3rd arg (0x155f34); a1 live across a test = dropped 2nd arg, type callee `(Obj*,int)` (0x2345f8); `ctor(p,1,4,1,1,0)` has a dropped 6th arg (`move t1,zero` in the slot) (0xdfdf8).
- Int `0` beside a pointer may be float (`mtc1 zero,$f12`): `f(0.0f,ptr,0)` (0x127d5c, 0x142f90).
- `(int)*(short*)(p+0x10)` args = `short` params (`int` schedules lh early) (0x101630); no `seh` in ret = `int` param (0x17d59c, 0xbd378, 0x1a444c, 0xd6b30, 0xed6c4).
- Unprototyped callee promotes float to double (`__extendsfdf2`): prototype `float` (0x97110). Typed pointer args fixed lower_bound arg setup (0xd9d84); `int` object param `param_1+0x2928` orders args unlike a `char*` struct: type bases as pointers (0x187308).
- Arg-load scheduling follows the callee's DECLARED param order: try all 24 (`F(void*,int c,float f,int b)` matched) (0x1550c0); float positions in the signature order the setup moves, 6 exact of C(11,3) (2nd float slot 6, 3rd slot 10, 1st 0..5): generate for 8+ args (0xb2218).
- EABI int/float params take independent regs (`f(void*,Ctx*,float)` = `f(void*,float,Ctx*)`); only prologue (`mov.s $f20,$f12` vs `move s0,a1`) and setup order show declared order (0x1532e4, 0x1b2180).

## 3. Types, signedness, widths, bit packing
- Odd-address globals are bytes (lbu), 2-mod-4 at most halfwords (0xdb7f4).
- Flags tested `!=0` that Gh types char/undefined4 are `unsigned char` (lbu) (0x19a19c, 0x15171c, 0xff7d8, 0x15435c, 0x17ce84, 0x131cf8); compared to 1/2 they are `char` (lb) (0x130654); plain `char` global = lb, ret lbu is `bool` (0x16a508).
- Gh `bool` results are often `int` returns, no `andi 0xff` (0x127870); bool/u8 callee `==0` gets `andi v0,0xff`, `!f()` drops it (0x88a44); int `return !b;` = `sltu;xori` (0x131d58).
- Ctor-like function Gh types void returns int when the call result is live in v0 at the join: `int r=F(p);if(r!=0)r=G(fmt,r);return r;` (0x10a900, 0x10aae4, 0x10a4d4, 0x10a6f8); void `r=F();if(r)G(fmt,r);` coalesces r into a1, `if((r=F())!=0)` hoists `move a1,v0` into a slot (0x10a4d4); `&o->cfg` not `p+0xc` keeps `addiu a0` in the jal slot (0x10a6f8).
- Generator `undefined4`-as-`float` typedef: an unused first param so typed moves the real pointer to a0; lwc1/swc1 copies need `float` fields (0x12e924).
- `signed char` member = -1 reuses the int -1 reg, `unsigned char = 0xff` doesn't (0x9547c); `char ch=*s;unsigned char c=ch;` = `lb;andi 0xff;..seb`, `unsigned char c=*s` = lbu (0x197834).
- Signed `bytes/4` is CSE'd everywhere; ret redoes it after the call only with different types: `int n=bytes/4;` + `size+=(long)bytes/(long)sizeof(T);` (0xd5304). `int n=last-first;` is CSE'd into `(last-first)*sizeof(T)`; ret: `int n=((char*)last-(char*)first)/(int)sizeof(T);` (0x146500).
- Packed RGBA: `c=(c&0xffffff00)|(unsigned char)((c&0xff)+d);` on `unsigned int`; 8-bit bitfields lbu/sb; getter `color&0xff` narrows to lbu; `short d=(short)(w*k-w)/2;` fixed lh order (0x10c69c, 0x112a80).
- Byte insert macro `(c&mask)|((v&0xff)<<k)` = `or old,new`; inline `unsigned WithX(unsigned c,unsigned char v){return (v<<k)|(c&mask);}` = `or new,old` (0xf4260).
- `(x&0xffff)>>12` is `ext` only as `(h>>12)&0xf` on `unsigned h`; `(h&0xfff)>=0x800?-1:(h&0x7ff)` puts andi in the bnezl slot; result-less stream-reader helper = `float F(void*)`, and `self->pts[i].x=F(s)` reloads the array ptr per store (0x1522b4, a stream-reader ctor).
- `lbu;or`+`sllv v1,one,n;seb;andi 0xff`, no `andi 0x1f` = `signed char m=1<<n;*(byte*)(p+0xf0)|=m;` (0x15d1e8).

## 4. Globals, addresses, addressing order
- Global used as struct base must be a pointer (int global, offsets >0x7fff: `addiu 0x7fff`+rest, swl/swr; ret lui/addu negative offset) (0x22c15c, 0x22c4ac).
- Gh numeric module addresses (`(T*)0x34179c`, `FUN(0x30fe20)`) are symbols (lui/addiu %hi/%lo, never ori): `&DAT_0034179c` (0x1b5594); `index+0x338b58` -> `(int)&DAT_00338b58+index` (0xee44c).
- Member access is char-pointer arithmetic: int-typed base `(base+i*4+0x3c)` swaps operands, `self->items[i]` or `char*` base `base+0x3c+i*4` matches (0x2535f0); `self->slots[self->cur]` (`struct Obj{char pad[0x198];int cur;char pad1[0x40];VC *slots[8];}`) = index first (0x17d59c).
- Offset-first addu: `int *p=(int*)F(..);p[i+1]=v;` (0xc5014); `off=i*12;r=(Row*)(off+(int)o->rows);` as comma operand (0x18f1ac); checked `struct V{int *data;unsigned size;}` `if(idx>=v->size){fprintf(stderr-field,msg);abort();}return &v->data[idx];` (0xe9418, 0x12dbb8, 0xf78ac, 0x18c9f4).
- Function-local static with guard: guard `char` (lb/sb), object `struct{char c;int i;}` zeroed per field, registration record passed as `DAT_xxxxxxxx` symbol (0xe9418 family).
- A global read in one switch case must be read inside it (at function top = prologue load); two switches' jump tables land in .rodata in REVERSE order (`rodata=` = the second's) (0x88a44).
- Literal operand of inline `min(const T&,const T&)` (`min(a.max_size(),(unsigned)0x7fffffff)`) = 4-byte .data constant (hstmatch UNPLACED_SECTION .data) (0x192a3c, 0xdfcb0); ret's stack temp (`sw v0,24(sp)` in slot) = inline function returning the constant by value (0x192a3c).
- Anonymous .data (array initialisers, const& literal temps, then strings in use order) placed with `data=` (0x1a0148); literals + first-defined `static int sock=-1;` reproduce the TU .data (0xbfb94).
- Decode a lui/lo pair with the SIGN-EXTENDED low half before naming a DAT_: `lui 0x34; lw -31032` = 0x3386c8, not 0x3486c8 (ds10, ds4 0x1233e0; NOTES 2026-10-21).

## 7. Registers and declaration order
- Saved regs follow LOCAL DECLARATION order, earlier-declared = HIGHER s-reg: loop index before pointer/offset (0x93484 `uVar3,pfVar2,iVar1`; 0x93cc8 `uVar3,iVar2,piVar1`; 0xff7d8; 0xfbbf8; delete loop `do{p=self->m[i];if(p){delete p;self->m[i]=0;}i++;q++}while(i<N)` ret index s2/ptr s1, Gh lists `int*pVar1;T*pVar2;int iVar3;` (0xcf474, 0x122a80, 0x11931c); `int iVar3;int iVar2;int*piVar1;` (0x15dec0, 0xbd704)).
- `for(i=0,p=tab;i<3;i++)` -> ret s1/s0 (0x1afe6c). Pointers live across a loop: ret `lw s0,root;addiu s1,a0,4` needs parent `Node*y=&t->header_;` declared BEFORE cursor `Node*x=root;`, `j=0;` first (0x19660c).
- 0x15171c (`in`,`a`,`b` before a call, `v` result): only order v,a,b (4 of 24). 0x18b3d4: index split from call-result temp (`j` before pointer)+`unsigned char` flag. 0x18a960: own index/pointer per loop, order `iVar1 iVar3 iVar2 iVar5 iVar4`. With 5-6 locals generate permutations (~0.5 s each).
- Gh's reused locals (`iVar3` index AND temp): block-scope `int i;T*p;` per loop (+`opt_strength_reduction off` for `*(int**)(base+i*4)`) (0xc82c8, 0x15a62c); a 2nd loop reusing the 1st's index permuted s0/s1/s2: fresh `for(int j..)` (0x97d64).
